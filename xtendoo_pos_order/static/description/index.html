Xtendoo POS Order Backend

Gestión de órdenes POS desde el backend

Características principales

✓ Configuración flexible

Cada punto de venta puede elegir entre usar la interfaz JavaScript estándar o gestionar órdenes directamente desde el backend de Odoo.

✓ Creación manual de órdenes

Habilite el botón "Crear" en las vistas de órdenes POS cuando el modo backend esté activado. Perfecto para TPV sin pantalla táctil.

✓ Validaciones de seguridad

Solo permite la creación manual cuando la caja está configurada en modo backend. Previene inconsistencias en los datos.

✓ Cálculos automáticos

Los totales, impuestos y descuentos se calculan automáticamente utilizando la lógica estándar del POS de Odoo.

Casos de uso

  • TPV tradicionales: Gestione ventas desde computadoras sin pantalla táctil
  • Backoffice: Cree órdenes telefónicas o por email directamente en el sistema
  • Integración ERP: Unifique el flujo de trabajo entre ventas mostrador y ventas normales
  • Formación: Entrene a su personal en un entorno más familiar (backend)
  • Personalización: Desarrolle flujos específicos sin modificar el frontend JS del POS

Instalación y configuración

  1. Instale el módulo desde Aplicaciones
  2. Vaya a Punto de Venta → Configuración → Puntos de Venta
  3. Seleccione el POS que desea configurar
  4. En Interface Configuration, elija Backend Orders Interface
  5. Guarde y abra una sesión
  6. ¡Comience a crear órdenes desde el backend!
