Sales Show Shipping Column

This module adds a shipping address column in the tree views of sale orders and customer invoices.

Features

✓ Sale Orders & Quotations

Displays shipping address in the tree view of quotations and sale orders.

✓ Customer Invoices

Displays shipping address in the tree view of customer invoices.

✓ Formatted Address

Shows a complete formatted address including:

  • Contact name
  • Street
  • ZIP code and city
  • State/Province
  • Country

✓ Optional Column

The column is marked as "optional=show", so users can hide or show it using the column selector.

Usage

  1. Install the module
  2. Navigate to Sales → Orders → Quotations or Orders
  3. The "Shipping Address" column will be visible in the tree view
  4. You can hide/show it using the column selector (gear icon)
  5. Same applies to Invoicing → Customers → Invoices
