This module adds a shipping address column in the tree views of:

* Sale Orders (Quotations and Sales Orders)
* Customer Invoices

The column shows a formatted shipping address including:
* Contact name
* Street
* ZIP and City
* State
* Country

Usage
=====

After installing the module:

1. Go to Sales > Orders > Quotations or Orders
2. The "Shipping Address" column will be available in the tree view
3. You can show/hide it using the column selector (optional="show")
4. The same applies to Invoicing > Customers > Invoices
