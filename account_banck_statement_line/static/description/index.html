Account Bank Statement Line - Full Edit

Versión: 17.0.1.0.0

Autor: Xtendoo Software S.L.U.

Licencia: LGPL-3

Descripción

Este módulo permite editar todos los campos del modelo de líneas de extracto bancario (account.bank.statement.line) en Odoo 17, proporcionando acceso directo a través de un menú dedicado bajo Contabilidad → Xtendoo.

✓ Características principales

  • Edición total de todos los campos de líneas de extracto bancario
  • Menú dedicado para acceso directo sin pasar por otras pantallas
  • Control de permisos mediante grupo específico
  • Trazabilidad completa con registro en chatter
  • Wizard de confirmación para ediciones en estados críticos
  • Auditoría con campo de motivo de ajuste manual

Funcionalidades

1. Interfaz de usuario mejorada

  • Vista tree editable en línea para cambios rápidos
  • Vista form completa con secciones organizadas
  • Smart buttons para navegación rápida
  • Filtros y búsquedas avanzadas
  • Badges visuales de estado

2. Seguridad y control

  • Grupo específico: Xtendoo - Editor líneas de extracto
  • Acceso también para usuarios con rol Asesor
  • Wizard de confirmación para estados críticos
  • Banner de advertencia en líneas conciliadas o posteadas

3. Auditoría y trazabilidad

  • Registro automático en chatter de todos los cambios
  • Campo obligatorio para documentar motivo del ajuste
  • Tracking de campos clave (fecha, importe, contacto, etc.)
  • Información de auditoría (creado por, modificado por)

4. Gestión de riesgos

  • Parámetro de configuración para activar/desactivar edición total
  • Advertencias visuales en formularios
  • Botón para recalcular totales y conciliación
  • Validaciones para prevenir descuadres

⚠ Advertencias importantes

  • Impacto contable: Editar líneas conciliadas puede afectar la contabilidad
  • Documentación: Siempre documenta el motivo del ajuste
  • Verificación: Después de ediciones, verifica que los totales cuadran
  • Permisos: Solo otorga acceso a usuarios de confianza

Instalación

  1. Actualizar la lista de módulos en Odoo
  2. Buscar "Account Bank Statement Line - Full Edit"
  3. Hacer clic en Instalar
  4. Asignar permisos a los usuarios autorizados

Configuración

El módulo incluye un parámetro de sistema para controlar la edición total:

Ruta: Configuración → Técnico → Parámetros → Parámetros del Sistema
Clave: account_banck_statement_line.allow_full_edit
Valores: True (activado) / False (desactivado)

Uso

  1. Navegar a: Contabilidad → Xtendoo → Líneas de extracto (edición total)
  2. Seleccionar una línea o crearla nueva
  3. Editar los campos necesarios
  4. Documentar el motivo del ajuste en el campo correspondiente
  5. Guardar los cambios
