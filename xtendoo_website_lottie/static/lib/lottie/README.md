# lottie-web

Descarga la librería oficial `lottie.min.js` desde el proyecto `lottie-web` y colócala en este mismo directorio con este nombre exacto:

`lottie.min.js`

Ruta esperada por el manifiesto del módulo:

`xtendoo_website_lottie/static/lib/lottie/lottie.min.js`

No se usa CDN para que el despliegue en producción sea autocontenido.
