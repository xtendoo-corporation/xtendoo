# Xtendoo Xtd Theme

Módulo de identidad visual para transformar el entorno de trabajo Odoo en una experiencia Xtd sobria, estable y minimalista.

## Alcance

- Sustituye referencias visibles de Odoo por Xtd en layout, login y promociones de marca.
- Usa dependencias OCA para eliminar referencias online, portal y correos sin duplicar lógica.
- Aplica una paleta compacta: naranja Xtd, granate profundo, negro técnico, blanco y grises suaves.
- Añade logo, símbolo y favicon vectoriales propios.

## Dependencias

- `web`
- `disable_odoo_online`
- `mail_debranding`
- `portal_debranding`

`website_debranding` queda fuera para no instalar `website` de forma implícita.
