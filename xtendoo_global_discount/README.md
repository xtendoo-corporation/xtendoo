# xtendoo_global_discount

Este módulo permite definir un descuento global en los contactos (clientes), que se aplicará automáticamente en las líneas de venta y factura al seleccionar un producto, salvo que el producto tenga activado el check "Sin descuento global".

## Características
- Campo "Descuento global" en la pestaña de ventas de los contactos.
- Campo booleano "Sin descuento global" en productos.
- Aplicación automática del descuento global en líneas de venta y factura.

## Instalación
1. Copia la carpeta `xtendoo_global_discount` en tu ruta de addons personalizada.
2. Actualiza la lista de aplicaciones y busca "Xtendoo Global Discount".
3. Instala el módulo.

## Uso
- Configura el descuento global en el contacto.
- Marca "Sin descuento global" en los productos que no deban recibir el descuento.
- Al crear ventas o facturas, el descuento se aplicará automáticamente según la configuración.
