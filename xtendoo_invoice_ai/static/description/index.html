🤖 Invoice AI - OpenAI Integration

Automatically import vendor invoices using OpenAI (ChatGPT) vision and structured extraction.

Odoo 18 OpenAI GPT-4o AI-Powered AGPL-3

✨ Key Features

📄 Multi-Format Support

Process PDF (multi-page) and images (JPG, PNG) of vendor invoices.

🌍 Multi-Currency

Automatically detects and handles different currencies (EUR, USD, GBP, etc.).

🏢 Multi-Company

Full support for multi-company environments with proper isolation.

🤝 Auto Supplier Creation

Automatically creates suppliers if not found in the database.

💰 Smart Tax Mapping

Intelligently maps extracted taxes to your Odoo tax configuration.

✅ Total Validation

Validates extracted totals against calculated amounts for accuracy.

📊 Job History

Track all imports with metrics like processing time and token usage.

🔒 GDPR Compliant

Configurable logging and optional file attachment for data privacy.

🚀 How It Works

  1. Upload: Upload a PDF or image of a vendor invoice
  2. Extract: OpenAI analyzes and extracts structured data
  3. Match: System matches or creates supplier
  4. Create: Draft vendor bill is created automatically
  5. Review: Review and validate the bill before posting
💡 Pro Tip: Works best with clear, high-resolution images. Supports Spanish, English, and other languages automatically.

⚙️ Installation

1. Install Python dependencies:

pip install openai pdf2image jsonschema

2. Install system dependencies (for PDF processing):

# Ubuntu/Debian
sudo apt-get install poppler-utils

# macOS
brew install poppler

3. Get OpenAI API Key:

  • Visit OpenAI Platform
  • Create a new API key
  • Configure it in Odoo: Settings → General → Integrations → OpenAI
⚠️ Note: This module requires a paid OpenAI API key. Token costs apply per API call based on invoice complexity.

📖 Usage

Import an Invoice

  1. Go to Accounting → Vendors → Import Invoice with AI
  2. Upload your invoice file (PDF/JPG/PNG)
  3. Configure options (company, journal, currency)
  4. Click "Analyze and Create Invoice"
  5. Review the created draft bill

View Import History

Go to Accounting → Vendors → AI Import History to see all past imports with detailed metrics.

🛠️ Configuration Options

  • OpenAI Model: Default gpt-4o (must support vision)
  • Max Pages: Maximum PDF pages to process (default: 10)
  • Temperature: 0.0 = deterministic, 1.0 = creative (default: 0.0)
  • Tolerance: Maximum total difference allowed (default: 0.02)

📊 Extracted Data

The AI extracts:

  • ✅ Supplier info (name, VAT, address, email, phone)
  • ✅ Invoice number and dates
  • ✅ Currency and payment terms
  • ✅ Line items (description, quantity, price, taxes)
  • ✅ Product codes (when available)
  • ✅ Calculated totals

🔐 Security & Privacy

  • Direct API calls to OpenAI (no intermediate storage)
  • Minimal logging without sensitive data
  • Optional file attachment (disable for GDPR compliance)
  • Role-based access control
