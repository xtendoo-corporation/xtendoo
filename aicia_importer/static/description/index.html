AICIA - Importador de Proveedores

Módulo para Odoo 19.0 que permite importar proveedores de forma masiva desde archivos Excel (.xlsx).

Características principales

  • ✓ Importación masiva de proveedores desde archivo Excel
  • ✓ Opción para actualizar proveedores existentes
  • ✓ Importación completa de datos de contacto (teléfono, email, dirección)
  • ✓ Creación automática de personas de contacto asociadas
  • ✓ Validación automática de NIF/CIF con código de país
  • ✓ Registro detallado de resultados de importación
  • ✓ Manejo de errores con reportes detallados

Cómo usar

  1. Vaya a: Ajustes → Técnico → AICIA → Importar Proveedores
  2. Seleccione el archivo Excel (.xlsx) con los proveedores
  3. Marque la opción "Actualizar existentes" si desea actualizar proveedores que ya existen
  4. Haga clic en "Importar Proveedores"
  5. Revise el resumen de importación

Formato del archivo Excel

El archivo debe contener las siguientes columnas en la primera fila:

  • ID_Proveedor: Referencia interna del proveedor
  • Nombre: Nombre del proveedor (obligatorio)
  • Nombre2: Segundo nombre o razón social adicional
  • CIF: NIF/CIF del proveedor
  • Telefono: Teléfono principal
  • TelefonoMovil: Teléfono móvil
  • Direccion: Dirección principal
  • Direccion2: Dirección adicional
  • Localidad: Ciudad
  • Cod_Postal: Código postal
  • Correo_Electronico: Email
  • Persona_Contacto: Nombre de la persona de contacto
  • Observaciones: Comentarios

Requisitos técnicos

Este módulo requiere la librería Python openpyxl.

Para instalarla: pip install openpyxl

Lógica de importación

  • Si el proveedor ya existe (búsqueda por referencia o CIF), se actualiza solo si la opción "Actualizar existentes" está marcada
  • Si no existe, se crea un nuevo proveedor
  • Los proveedores se marcan automáticamente como "Es un proveedor"
  • Si hay persona de contacto, se crea como contacto hijo del proveedor
  • El NIF/CIF se ajusta automáticamente con el prefijo "ES" si no tiene código de país
