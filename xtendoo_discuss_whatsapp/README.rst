WhatsApp-inspired visual theme for Odoo Discuss.

This module changes the Discuss interface with backend assets only. It
keeps Odoo's standard mail/discuss behavior and applies a familiar chat
layout: green header accents, chat wallpaper, rounded message bubbles,
compact conversation list and rounded composer controls.
