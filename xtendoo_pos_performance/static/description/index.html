Xtendoo POS Performance

Optimización completa del rendimiento del Punto de Venta

¿Qué hace este módulo?

Este módulo optimiza de forma integral el rendimiento del TPV en bases de datos con catálogos grandes (35.000+ productos) mediante múltiples estrategias:

  • Límites de carga inicial: Carga solo los registros necesarios al abrir el POS
  • Índices PostgreSQL: Acelera búsquedas por código de barras, referencia y nombre
  • Autovacuum optimizado: Mantiene la base de datos en condiciones óptimas

Optimizaciones incluidas

1. Límites de Carga

Configura cuántos productos y clientes se cargan al iniciar el POS:

  • point_of_sale.limited_product_count
  • point_of_sale.limited_customer_count

El resto se carga bajo demanda, manteniendo una experiencia fluida.

2. Índices PostgreSQL

Índices optimizados en tablas críticas:

  • Código de barras y referencia interna
  • Búsquedas de texto con pg_trgm
  • Búsquedas sin acentos con unaccent
  • Filtros de disponibilidad en POS

3. Autovacuum Optimizado

Configuración personalizada de mantenimiento automático:

  • Umbrales ajustados para product_template
  • Umbrales ajustados para product_product
  • Menor impacto en operaciones en caliente

4. Instalación Automática

Al instalar el módulo se crea automáticamente:

  • Extensiones PostgreSQL (pg_trgm, unaccent)
  • Todos los índices necesarios
  • Configuración de autovacuum
  • Parámetros con valores por defecto

Valores recomendados

Tamaño del catálogo Valor recomendado
< 5.000 productos 0 (sin límite)
5.000 - 15.000 productos 500 - 1.000
15.000 - 50.000 productos 300 - 500
> 50.000 productos 200 - 300

Configuración

  1. Ir a Ajustes → Punto de venta
  2. Desplazarse hasta la sección "Rendimiento"
  3. Ajustar los valores según el tamaño de tu catálogo
  4. Guardar y listo
