Xtendoo POS Performance

Mejora drásticamente el rendimiento del Punto de Venta

¿Qué hace este módulo?

Este módulo optimiza el tiempo de arranque del TPV en bases de datos con catálogos grandes (por ejemplo, 35.000 productos o más).

Limita la carga inicial de productos y clientes, permitiendo que el POS se abra rápidamente y cargue el resto de datos bajo demanda.

Características principales

Arranque ultra-rápido

Reduce el tiempo de apertura del POS hasta un 90% en catálogos grandes

Configuración visual

Ajusta los límites desde Ajustes sin tocar código ni parámetros técnicos

Interfaz en español

Todos los textos y ayudas en español para usuarios funcionales

100% compatible

Compatible con Odoo 19.0 Community y Enterprise, multi-compañía

¿Cómo funciona?

El módulo configura los parámetros internos de Odoo:

  • point_of_sale.limited_product_count: Limita productos en el primer batch
  • point_of_sale.limited_customer_count: Limita clientes en el primer batch

El resto de productos y clientes se cargan automáticamente cuando el usuario los busca, manteniendo una experiencia fluida sin sacrificar funcionalidad.

Valores recomendados

Tamaño del catálogo Valor recomendado
< 5.000 productos 0 (sin límite)
5.000 - 15.000 productos 500 - 1.000
15.000 - 50.000 productos 300 - 500
> 50.000 productos 200 - 300

Configuración

  1. Ir a Ajustes → Punto de venta
  2. Desplazarse hasta la sección "Rendimiento"
  3. Ajustar los valores según el tamaño de tu catálogo
  4. Guardar y listo
