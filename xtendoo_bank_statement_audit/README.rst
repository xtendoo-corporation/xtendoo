Módulo de auditoría de extractos bancarios para Odoo 18.0 que permite visualizar
todos los movimientos bancarios con saldo acumulado calculado eficientemente.

**Table of contents**

.. contents::
   :local:

Características
===============

* Vista de auditoría con saldo acumulado por diario
* Filtros avanzados por diario, partner, fechas, conciliación
* Agrupaciones por diario, partner, extracto, fecha
* Exportación a Excel (XLSX) con KPIs
* Rendimiento optimizado con SQL window functions
* Soporte multi-compañía

Uso
===

#. Ir a Contabilidad > Auditoría Bancaria > Movimientos de Extracto
#. Usar los filtros para seleccionar el rango de datos deseado
#. Usar el botón "Exportar a Excel" para descargar el archivo XLSX
